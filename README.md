# awtoday

ActivityWatch의 AFK 기록을 요약하고, 날짜별 추가·제외 시간을 반영하는 작은 macOS 앱입니다.
Swift/AppKit/SwiftUI로 동작하며 Bash, curl, jq에 의존하지 않습니다. 기존 CLI는 그대로 둘 수 있습니다.

## 사용

- 상단에서 날짜를 선택하거나 이전·다음·오늘로 이동합니다.
- **버킷 · 자동**은 `aw-watcher-afk_`로 시작하는 버킷 중 마지막 갱신일이 가장 최근인 것을 선택합니다. 갱신일이 없으면 생성일을 사용합니다.
- 버킷 메뉴에서 직접 선택하면 날짜를 바꾸거나 앱을 다시 열어도 유지됩니다. 서버에서 버킷이 없어진 것이 확인될 때만 자동 선택으로 돌아갑니다. 연결 실패로 선택을 바꾸지는 않습니다.
- 큰 숫자는 **활동 − 제외 + 추가**입니다. 작은 합계나 보정 목록은 해당 구간에서 실제 반영된 분량을 표시합니다. 내부 계산은 초 단위이며 화면은 분 미만을 생략합니다. 합계에 포인터를 올리면 초까지 볼 수 있습니다.
- 타임라인은 하루 전체를 같은 길이의 두 줄로 나눕니다. 파랑은 활동, 아래 초록 선은 추가, 주황 선은 제외입니다.
- 막대를 양방향으로 드래그해 1분 단위로 범위를 잡고, 시각과 추가·제외 구분을 확인해 저장합니다. 두 줄에 걸쳐 드래그할 수도 있습니다. **시간 지정** 버튼으로도 편집기를 열 수 있습니다.
- **− 제외 / + 추가** 합계를 누르면 목록이 펼쳐집니다. 항목을 누르면 막대에 테두리와 끝 시각이 표시됩니다. 항목 오른쪽 메뉴에서 수정·삭제합니다.
- **추이**는 선택 날짜까지 7일 또는 30일의 보정된 합계를 표시합니다. 보정 목록과 추이는 같은 확장 공간을 사용합니다.
- 목록이나 추이를 펼쳐도 상단 합계와 타임라인의 위치는 유지됩니다. 아래 공간이 부족하면 상세 영역 안에서 스크롤합니다.
- 새로고침은 오른쪽 아래 버튼 또는 `⌘R`입니다. `Esc`는 편집기, 선택 표시, 창 순서로 닫습니다.

## 하루와 시간 계산

ActivityWatch의 `startOfDay` 설정을 읽습니다. 예를 들어 04:00이면 선택 날짜 04:00부터 다음 날 04:00까지입니다. 앱 시작 시 현재 시각이 속한 날짜를 선택합니다. 수동 범위 사이의 빈틈에 있으면 달력상의 오늘을 선택합니다.

합계 위의 작은 시간 범위를 눌러 해당 날짜의 시작·종료를 바꾸거나 기본값으로 복원할 수 있습니다. 시작은 선택 날짜, 종료는 당일 또는 다음 날입니다. 이웃 날짜의 유효 범위와 겹치면 저장하지 않습니다. 이웃 날짜를 먼저 직접 조정해야 하며, 앱이 다른 날짜를 자동으로 이동하지 않습니다. 범위 사이의 빈틈은 합산하지 않습니다. 날짜 범위는 버킷과 독립이고, 보정 기록은 날짜·버킷별로 저장합니다.

기준 활동은 설치된 ActivityWatch 서버의 `flood(query_bucket(...))` 결과에서 `not-afk` 구간을 가져와, 하루 범위와 현재 시각으로 자르고 겹치는 구간을 합친 것입니다. 앱이 별도의 빈틈 연결 규칙을 추가하지 않습니다.

- **제외**: 지정 구간과 기준 활동이 겹치는 시간만 뺍니다.
- **추가**: 지정 구간 중 기준 활동이 없는 시간만 더합니다. AFK와 기록이 없는 구간 모두 포함합니다.
- 보정끼리는 종류가 같아도 겹칠 수 없습니다. 끝과 시작이 맞닿는 것은 가능합니다.
- 미래 시간은 합산하지 않습니다. 원본 ActivityWatch 기록은 수정하지 않습니다.
- 하루 범위를 바꿔도 기존 보정의 실제 시각은 보존합니다. 새 범위와 겹치는 부분만 반영하고 범위 밖 항목도 0분과 사유를 표시합니다.
- 연결 실패는 0시간으로 표시하지 않습니다. 오류를 표시하고 편집을 막습니다.

## 저장과 Google Drive

```text
~/Documents/AppData/awtoday/
  settings.json   # 버킷 선택, 웹페이지 이름·주소·창 크기
  state.json      # 날짜별 하루 범위와 날짜·버킷별 추가/제외 구간
```

버전이 있는 JSON을 원자적으로 저장합니다. 파일이 손상되거나 지원하지 않는 버전이면 초기화하거나 덮어쓰지 않습니다. 저장 직전과 새로고침·앱 활성화 시 외부 변경을 확인합니다. 외부 변경을 발견하면 다시 읽거나 새로고침을 요청합니다.

**Google Drive 설정은 앱과 독립입니다.** 사용자가 Drive 데스크톱에서 `~/Documents/AppData`를 동기화 대상으로 추가합니다. awtoday에 Google 로그인이나 Drive API 권한은 필요 없습니다. 이 구성은 한 Mac의 백업·복원용이며, 여러 Mac에서 동시에 편집하는 용도는 아닙니다.

복원할 때는 awtoday를 종료하고 두 JSON 파일을 같은 경로에 복원한 후 다시 실행합니다. ActivityWatch 원본 DB는 이 폴더에 없으므로 원본 활동 기록은 별도로 백업해야 합니다. 다른 Mac에서 복원한다면 버킷 ID와 로컬 시간대를 확인하세요. 로그인 쿠키는 이 폴더나 Drive에 저장하지 않습니다.

## 저장한 웹페이지

하단 웹페이지 버튼으로 자주 사용하는 HTTPS 페이지를 바로 엽니다. 처음 사용할 때 버튼 이름과 주소를 등록하며, **⋯ → 웹페이지 설정**에서 바꿀 수 있습니다. 이름·주소·창 크기는 사용자 Documents 아래의 `settings.json`에만 저장하며 소스 코드에 기본 주소를 넣지 않습니다.

내장 브라우저는 WebKit 영구 저장소를 사용합니다. 로그인과 페이지 기능은 사이트 자체가 처리하며, 앱은 페이지 스크립트를 주입하거나 DOM을 검사하지 않습니다. 자동 입력·저장 기능도 제공하지 않습니다. Chrome 쿠키나 비밀번호를 가져오지 않고, 인증 데이터는 WebKit 저장소에서 관리합니다. 서버가 세션을 만료시키면 다시 로그인해야 할 수 있습니다.

웹페이지 창을 조절하면 마지막 크기를 저장합니다. 창을 다시 열거나 앱을 재실행하면 복원하고, 현재 화면보다 크면 화면에 맞게 줄입니다.

## 빌드와 설치

macOS 13 이상, Apple Silicon, Xcode 또는 정상 설치된 Command Line Tools가 필요합니다. ActivityWatch 서버는 `http://localhost:5600`에서 실행되어야 합니다.

```sh
make app           # build/awtoday.app
make test          # 시간 계산·날짜 경계·저장 검증
make live-check    # 로컬 AW에 읽기 전용 조회로 검증
make model-check   # 임시 저장소에서 선택 유지·요청 취소·추이·오류 검증
make previews      # 창을 띄우지 않고 자체 뷰를 렌더링; build/previews
make install       # 기존 앱 백업 후 /Applications/awtoday.app에 설치
```

설치 시 기존 앱은 프로젝트의 `backups/<시각>/awtoday.app`으로 옮깁니다. `make clean`은 이 백업을 지우지 않습니다. 되돌릴 때는 앱을 종료한 뒤 백업 앱을 `/Applications/awtoday.app`으로 복원합니다.


`redefinition of module 'SwiftBridging'` 오류는 로컬 Swift 도구 설치 문제일 수 있습니다. `swift -e 'import Foundation; print("ok")'`로 확인한 뒤 Command Line Tools 또는 Xcode 설치를 점검하세요.

## 코드

- `AwTodayPopup.swift`: 앱 시작과 창 관리
- `Sources/ActivityWatchAPI.swift`: 비동기 조회와 JSON 날짜 처리
- `Sources/TimeCore.swift`: 구간 합집합, 보정, 하루 범위
- `Sources/FileStore.swift`: JSON 저장 및 외부 변경 감지
- `Sources/AppModel.swift`: 선택, 요청 취소, 화면 상태
- `Sources/MainView.swift`, `TimelineView.swift`, `Editors.swift`: 화면과 편집
- `Sources/WebPageBrowser.swift`: 사용자 설정으로 여는 범용 WebKit 창
